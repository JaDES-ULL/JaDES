# JaDES Core - Funcional

`jades-core` implementa el **motor de simulación** y los patrones de flujo. Define la ejecución de eventos, recursos, elementos y la coordinación de actividades.

## Funciones principales

- **Motor de eventos**: planificación y ejecución discreta.
- **Gestión de recursos**: tipos, disponibilidad, adquisición y liberación.
- **Elementos**: instancias, jerarquía y movimientos.
- **Flujos**: composición de actividades y patrones WFP.
- **Información**: emisión de eventos de simulación y listeners.
