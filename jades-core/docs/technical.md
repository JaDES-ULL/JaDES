# JaDES Core - Técnica

## Build

```bash
mvn -pl jades-core -am test
```

## Dependencias internas

- `jades-api`: contratos públicos.
- `jades-utils`: funciones, I/O y utilidades.

## Puntos de extensión

- Implementación de flujos personalizados.
- Listeners para `IPieceOfInformation`.
- Tipos de elementos y recursos específicos del dominio.
